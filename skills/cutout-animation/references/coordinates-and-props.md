# 坐标、肢体与道具

这些规则是素材处理和绑定约束，不是已经解决的导演或表演方案。

## 标定记录

保存每幅基准和供体的尺寸、SHA-256、坐标单位和原点。记录源像素空间到角色统一空间、角色父空间到场景空间的变换；像素坐标以左上为原点、y 向下时明确写出。保存骨盆／座面接触点、脚底、颈部、肩、肘、腕、袖口共享边界、握点、保护区与允许动作范围。每个点都需在原图上带名称显示，不能仅在 JSON 中存在。

裁切包围盒只用于减少空白计算。裁切偏移必须加回，禁止用每张差分的包围盒中心重新定位人物。不同手姿不能以“让手碰到道具”为理由拉长整条手臂。

## 肢体校准

比较同视角基准与供体的肩—肘、肘—腕长度、腕与袖口宽度、连接角度及完整轮廓。透视改变时不套用另一视角的平面长度；输出肩肘腕标记图并根据该姿态重新校准。允许偏差由实际标定和动作目标确定，不临时扩大阈值以放过失败。

合格差分包含整个需要替换的结构：袖口、前臂、手掌、手指和描边的归属明确。旧手从身体层清除；替换边界不能留下第二个手、断开的袖口或长出衣服的线。缺少合适视角的供体时，先报告缺失姿态素材；用户允许新增后另建素材版本，再分区和验收，不把旧手透视拉伸成新手。

坐姿以骨盆／座面接触点为根，座椅另有地面锚点。头部保持刚性；不要用整图软变形让眼镜、头骨或衣领跟着身子弯曲。检查静止、最大动作、表情切换前后及动作返回位置。

## 持物与遮挡

手与道具在接触期共享握点：`T道具世界 = T角色世界 · T持物局部 · T道具相对握点`。局部接触关系在该阶段恒定，不能分别在世界坐标插值后碰巧靠近。表面内容跟随道具面变换；盖章检查章底接触平面、手腕姿态与纸面透视，不只比较图像旋转角。

放手显式记录释放时刻，将最后世界姿态传给独立运动；手随后收回。进入桶内时，纸由桶前沿遮挡；落点与遮挡边界来自同一场景配置。角色、柜台和道具都有前后层归属，不能以单一全景贴图遮住应在前方的身体。

输出接触点轨迹、前后层编号与释放前后关键帧；检查轮廓和越界。数值接触误差接近零仍可能对应错误的画法、空间或透视，必须查看实际画面。
