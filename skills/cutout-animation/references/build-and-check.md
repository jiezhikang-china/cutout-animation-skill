# 构建与检查

## 输入与版本

工程入口以当前运行说明为准。锁定原图、供体、标定配置、音频和认可检查帧的 SHA-256，记录依赖版本和帧率。输入变化后新建版本与标定；认可帧不是可自动更新的测试答案。编辑剧本、冻结样片与完整候选分别保存，不互相反向覆盖。

每次构建独立目录。失败保留原图标记、遮罩、差异图、日志与报告，不发布为已通过。发布技能只打包技能及必要工具，不连带上传原画、音频、账户资料、浏览器配置或私人邮件。

## 像素检查工具

`scripts/audit_raster.py` 的图片使用同尺寸 RGBA 源图；遮罩为同尺寸灰度图，非零表示允许替换／保护区域。

```text
python scripts/audit_raster.py replacement --base base.png --candidate blink.png --mask eye-mask.png --protected glasses-mask.png --report checks/blink.json
python scripts/audit_raster.py assembly --base base.png --layers body.png arm.png --report checks/zero.json
python scripts/audit_raster.py exact --base accepted.png --candidate new.png --report checks/golden.json
```

替换检查：区外任何 RGBA 变化为零；保护区任何变化为零；alpha 变化为零。零动作重建：按传入顺序从底到顶合成，alpha 与所有可见 RGB 恢复原图；alpha 为零处隐藏 RGB 不作为可见误差。精确回归：全部 RGBA 相同，包括透明像素。故意改变 alpha 的新轮廓不属于局部表情替换，按新素材任务检查。

成功退出码 0，指标失败退出码 2，输入错误退出码 1。报告记录比较图片的哈希、尺寸、指标和失败位置差异图。脚本没有接缝求逆、解剖、透视或语气判断能力；用项目原有压力测试检查雅可比、逆解残差、接缝权重、固定根与脚底。实际动作和加大幅度测试单独记录。

## 排错经验

- 临时图像不能仅用 `id(image)` 作缓存键：对象销毁后标识可能复用，让另一个场景取到旧画面。使用素材版本／表情／尺寸／变换等语义键；缓存保留原对象或使用内容摘要，像素变更必须失效。通过交替场景与实际输出帧确认修复。
- Windows 中文路径的图片写入可能失败却没产生预期文件。优先 Pillow 保存，或 `cv2.imencode` 后写字节；检查返回值、文件存在且能重新打开，不能只检查保存函数执行过。
- 所有变换直接从源纹理采样到目标帧，先预乘 alpha、插值、恢复普通 RGBA；不在裁切小图和整帧间反复缩放。
- 时间线以整数帧编号为权威。分段场景用段起点加局部 `n / fps`；不得把小数秒多次四舍五入得到前一帧并误判。记录切点前、切点、切点后的真实帧号。

## 证据层次

自动指标、人工查看与用户接受是三种状态。检查需解码真实 MP4，包含最大动作、闭眼、嘴形切换、接触／放手和遮挡边界，而非只抽美观静帧。连续帧差异和运动峰值帮助定位抽动，不能单独证明动作自然。声音需试听；字幕需检查文字、时序、遮挡和说话人配色。

任何图像或局部样片通过，都不能替代剧情、分镜、剪辑节奏和转场检查。本技能不提供一套已经验收的完整影片导演方案。
