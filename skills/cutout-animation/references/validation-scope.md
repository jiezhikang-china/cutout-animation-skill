# 方法的验证范围

技能来自使用已有 Q 版位图、供体差分与程序渲染的动画工程，整理时间 2026-10-11。

## 可以沿用的技术基础

认可基准是 region-v1 的 10 秒 C 样片。具体涵盖右侧助手的区域归属、原差分局部复制、固定镜框与眉毛、手部完整分区、共享袖口接缝、重心／脚底固定及高清源纹理直接采样。Claude 表情沿用先前认可素材；不能声称所有角色都经过相同分区验收。

基础设施重构以六张认可帧精确一致为约束。这验证重构没有改变既定画面，不证明既定画面在其他场景、角度或动作中有效。新动作、角色、视角需要自己的标定与查看。

后续局部样片得到过认可，包括完整手臂落桶、连续柜台背景与盖章、封禁邮件与退款结尾的局部呈现。它们支持记录完整肢体、持物归属和遮挡的处理要求，不支持把整片列为合格或把特定动作参数推广到其他画面。

## 尚未通过

SVG 矢量化、GIMP 修绘、旧整图差分切换等实验不是稳定基准，不因工具可用而自动改走这些路径。音频时间线处理与声线情感质量分别验收，数值同步不代表人声自然。

技能带有检查工具和方法说明，不附原工程角色原画、官方录音、第三方封禁邮件或已认可片段。使用者需提供自己的素材和基准；没有输入时先标定，不凭描述编造验收记录。
