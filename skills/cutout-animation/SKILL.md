# 原画差分与纸片动画

保留用户认可的造型、画风和演出形式，通过可检查的图像分区、供体复制和局部绑定完成动作。数学约束通过不等于视觉正确。

## 开始工作

先读项目工作约定、当前入口与认可状态。已有稳定配置和构建工具时复用它们，不依据旧实验文件名另选流程。区分用户编辑剧本、冻结样片与完整候选；不把短片验收推广到全部角色。

处理区域、表情或接缝时读 [区域与绑定](references/region-and-rig.md)。处理手臂、坐姿或持物时读 [坐标、肢体与道具](references/coordinates-and-props.md)。处理对白、字幕或成片时读 [声音与交付](references/audio-and-delivery.md)。工程排错和构建回归读 [构建与检查](references/build-and-check.md)。确认可沿用范围时读 [验证范围](references/validation-scope.md)。

## 核心工作顺序

1. 检查原图实际像素、透明度和供体差分。不能为修闭眼或嘴形重新生成整个人物。
2. 将部件种子、保护区域、坐标锚点和参数保存成配置，并绑定源图尺寸与校验值。
3. 先输出原图标记、区域归属、独立部件及局部差分图；检查完整轮廓、填色、边界归属与遮罩泄漏，再做动画。
4. 以真实骨盆、颈部、接缝和脚底建立共同坐标；局部动作不能牵动无关衣服或身体。手握道具使用同一局部握点与父变换，松手后再切换归属。保持既定演出要求，不以随机摆动代替动作。
5. 直接从高分辨率源纹理采样到成片尺寸，正确处理透明颜色。核对实际导出的画面与声音。

## 验证与基准

检查遮罩外像素、固定部件、零动作重建、关节与脚底、动作逆解及变形折叠；同时查看原尺寸表情图、最大动作和眨眼帧。坐标一致不能证明手的长度、轮廓与透视正确。

对工程重构，用认可画面做精确回归。对用户要求的有意改动，另建版本、检查差异并保留旧版，不为通过检查悄悄更新认可值。新输出写独立目录，固定输入与原样片不默认覆盖。

可用 [像素检查脚本](scripts/audit_raster.py) 检查替换区外、保护区、alpha、零动作重建及精确回归。依赖 Pillow 与 NumPy；用法见 [构建与检查](references/build-and-check.md)。该脚本不能判断手是否画对、透视是否合理或演出是否自然。

使用现有项目的运行说明。没有工程时建立最小可重复构建，记录原图、种子、配置、依赖版本、时间线、检查和交付文件；不搬入与目标无关的技术实验。

## 交付范围

分别记录自动检查、实际查看／试听与用户认可范围。检查通过只能描述对应输入、角色、姿态与时间段。分镜、叙事节奏、场景转场及声音表演需要各自验收，不能由像素或几何指标推导。若用户停止作品制作、只要求总结工作流，完成技能整理，不继续修改影片。
